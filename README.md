# HC-index: Data and Analysis Code

This repository contains data and analysis code for investigating the HC-index across human gut microbiome cohorts, animal microbiomes, and a dietary fiber intervention study.

The analyses include HC-index calculation using a selected set of 17 taxa, associations with alpha diversity and participant metadata, comparisons across geographic regions, and baseline-adjusted changes following dietary fiber intervention. Additional datasets include metagenomic functional profiles and species-level dietary information.
